# Remote Sensing and GIS – Terrain Analysis

## Project Overview
This project focuses on generating terrain derivatives from Digital Elevation Model (DEM) satellite data using QGIS.

## Internship
India Space Lab – Winter Internship Training Program

## Objectives
- Generate contour maps from DEM data.
- Analyse terrain slope and aspect.
- Generate hillshade visualisations.
- Understand elevation characteristics of a Himalayan watershed.

## Tools Used
- QGIS 3.44
- Digital Elevation Model (DEM)
- WGS84 / UTM Zone 45N
